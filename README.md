# senthurvel — portfolio v3

Personal site of Senthurvel D, frontend developer (MERN), Coimbatore.

Layout, interactions and motion reverse-engineered from [fabwaseem.com](https://fabwaseem.com) (blueprint: `reports/Fabwaseem site reverse engineering.md`, kept local). All copy, projects and assets are Senthurvel's own; no code, text or imagery from that site is used.

## Stack

Vite · React 19 · TypeScript (strict) · Tailwind CSS v4 · Motion (`LazyMotion` + `m`, `useScroll`) · Lenis (≥1024px, driven by Motion's frame loop) · React Router 7 · Radix Dialog · cmdk · Lucide + Simple Icons · Urbanist / Geist Mono (self-hosted) · Vitest + Testing Library.

## Commands

```
npm run dev | build | typecheck | lint | test
```

## Content

Everything lives in `src/content/site.ts`.
- Text with a `[BRACKET]` placeholder is never rendered.
- Project images: generated by `npm run shots` (see below); placeholder frames show until a project has them.
- Live links: set `href` / `repo` on a project.
- Hero 3D asset: set `hero.media.poster` and `hero.media.video` (the video is scroll-scrubbed on desktop).
- Blog / guides / tools stay hidden (404, not in nav) until their arrays have entries.

## Project images

`npm run shots` screenshots each project's real site with Playwright (desktop 1440×900 @2x, phone 390×844 @3x), composes them into art-directed slots by rendering HTML templates in headless Chromium, and exports WebP at several widths, with no image dependencies. Recipes live in `scripts/shots/manifest.mjs`; titles and stacks come from `site.ts`.

| Slot | Size | Used by |
| --- | --- | --- |
| `cover` | 16:10 poster: title, window, phone, chips | /projects grid, marquee, case-study hero |
| `tall` | 3:4: window + phone | home card main slot (desktop) |
| `details` ×2 | 1:1: zoomed crop or single phone | home card side slots |
| `gallery` | 16:10: window or three phones, with alt text | case-study gallery |

```sh
npm run shots                       # everything
npm run shots -- --only medaac      # one project
npm run shots -- --compose          # re-compose from the last captures (offline)
npm run shots -- --explore <slug>   # viewport frames to choose scroll targets for a new project
```

Output: `public/images/projects/<slug>/` and `src/content/shots.json`. Raw captures go to `scripts/shots/.raw/` (git-ignored). Needs Node ≥ 22.18 (it imports `site.ts` directly) and a Chromium: Playwright's (`npx playwright install chromium`) or `SHOTS_CHROME=<path to chrome>`. Musix has no deploy: start its client on :5181 (and its API on :5001 for search results) first.

## Features

Floating pill nav (hides on scroll) · full-screen blind menu · Ctrl/Cmd+K palette · custom cursor (link / hug / label / text modes) · magnetic buttons (home) · back-to-top + theme toggle with circular View-Transition reveal (`D` key) · 2px scroll progress · film grain · first-visit preloader · two-layer page curtain · fit-to-width steel H1 · two-row scroll-reactive marquee · word-by-word scroll reveal · accordion lanes · sticky stacked case-study cards · 4-step contact form (draft saved locally, opens your mail app).

Reduced motion: no Lenis, cursor, magnet, curtain, preloader or scrubbing; all content at rest.

Home also has a **Toolkit** section (`skills` in site.ts): a hairline-ruled grid of tool logos with group filters. The footer has an interactive globe card (`src/components/ui/globe.tsx`, cobe).
