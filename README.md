I'm Senthurvel, a frontend developer from Coimbatore. I build fast, motion-rich React frontends and the Node and MongoDB backends behind them. Right now I'm a web developer intern at Thulir Media, and I'm open to frontend roles in Chennai, Bengaluru or remote.

## Built with

| Layer | Tools |

## Inside

- Graphite 3D cube hero
- Blind-curtain page transitions
- Sticky stacked case-study cards
- Word-by-word scroll reveals and a scroll-reactive marquee
- Custom cursor, magnetic buttons, `Ctrl/Cmd + K` command palette
- Light/dark theme with a circular reveal (`D` key)
- Interactive globe in the footer
- Reduced motion respected: all content at rest

## Run locally

Needs Node ≥ 22.18.

```sh
npm install
npm run dev
```
